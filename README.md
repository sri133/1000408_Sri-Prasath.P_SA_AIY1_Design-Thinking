## 🧭 1. Project Title & Objective

**Project Title:**
SA Hospital – Smart Patient Queue Management System

**Objective:**
The aim of this project is to improve the hospital waiting experience by reducing patient stress, anxiety, and uncertainty. The prototype focuses on providing real-time queue updates, engaging distractions, and personalized support to create a calm and patient-friendly environment.

**Target Audience:**

* Patients (children, adults, elderly)
* Caregivers
* Hospital staff

**Scenario Context:**
This project is based on **Scenario 2: Create Smart Solutions for Hospital Queues**. It reimagines hospital waiting areas using design thinking to transform stressful waiting into a supportive and engaging experience.

---

## 🧠 2. Design Thinking Overview

### 🔍 Empathize & Define

To understand user needs, a **survey was conducted using Google Forms**, and responses were collected and analyzed.

🔗 **Survey Form:**
https://docs.google.com/forms/d/e/1FAIpQLSffbbajKLn5QgStdlhDmTYyETytwft7jaqufKz7GkVhtrdoTw/viewform

🔗 **Responses Sheet:**
https://docs.google.com/spreadsheets/d/1sPqeSZ90QhA9eWSTWQ-v7CBwhKF6o1XB4g6SNaCU6Oc

**Key Insights:**

* Patients feel anxious due to **uncertain waiting times**
* Long queues create **frustration and boredom**
* Lack of engagement increases stress levels
* Elderly and children face more discomfort

**Personas Created:**
10+ personas were developed representing:

* Elderly patients needing clarity
* Children needing engagement
* First-time visitors feeling nervous
* Chronic patients needing calm environments

**Problem Statement:**
*How might we transform hospital waiting into a calm, engaging, and informative experience that reduces anxiety and improves patient satisfaction?*

---

### 💡 Ideate

Based on research insights, multiple ideas were generated and refined into key features.

**Core Features (Compulsory):**

1. **Queue Progress Tracker** – Real-time queue position and waiting time
2. **Distraction Hub** – Calming videos, VR-like experience, and entertainment
3. **Silent Pager Notifications** – Alerts when patient turn is near
4. **Mood-Based Interactions** – Breathing exercises and calming suggestions
5. **Feedback Section** – User input on stress levels and experience

**Additional Ideas Implemented:**

* Personalized patient updates
* Simple and accessible interface
* Stress-reducing UI design

---

### 🧪 Test

The prototype was tested with 7 users to evaluate usability and effectiveness.

**Testing Process:**

* Users interacted with the prototype
* Observed navigation and reactions
* Collected feedback on experience

**Key Feedback:**

* Users liked real-time queue updates
* Distraction features helped reduce boredom
* Interface needed clearer buttons

**Improvements Made:**

* Simplified navigation
* Improved visibility of buttons
* Enhanced calming design elements
